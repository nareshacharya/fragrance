## Getting Started

### System Requirements

- **Browser**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Screen Resolution**: Minimum 1024x768 (recommended 1920x1080)
- **Internet Connection**: Stable broadband connection
- **JavaScript**: Must be enabled

### First Login

1. **Access the System**: Navigate to your organization's Fragrance Management System URL
2. **Login Credentials**: Use the credentials provided by your administrator
3. **Password Reset**: If you need to reset your password, click "Forgot Password" on the login page
4. **Two-Factor Authentication**: Follow the setup process if required by your organization

### Navigation Overview

The system uses a modern, intuitive interface with:

- **Top Navigation Bar**: User profile, notifications, and system settings
- **Sidebar Navigation**: Main menu with feature access
- **Breadcrumb Navigation**: Shows your current location
- **Quick Actions**: Common tasks accessible from multiple locations

## Perfume Management

### Creating a New Perfume

1. **Navigate**: Go to Perfumes → Create New
2. **Basic Information**:
   - **Name**: Enter a descriptive name
   - **Description**: Provide detailed description
   - **Category**: Select from available categories
   - **Tags**: Add relevant tags for organization

3. **Formula Assignment**:
   - **Create New**: Start with a new formula
   - **Use Existing**: Select from existing formulas
   - **Import**: Upload formula from file

4. **Project Association**: Link to relevant project
5. **Save**: Create the perfume record

### Perfume Categories

The system supports various perfume categories:

- **Fresh**: Light, clean fragrances
- **Floral**: Flower-based compositions
- **Oriental**: Spicy, exotic blends
- **Woody**: Earthy, forest scents
- **Citrus**: Bright, zesty notes
- **Gourmand**: Edible, sweet fragrances
- **Aquatic**: Marine, water-inspired
- **Spicy**: Warm, aromatic spices

### Perfume Status Workflow

1. **Draft**: Initial creation, work in progress
2. **In Review**: Submitted for approval
3. **Approved**: Ready for production
4. **In Production**: Currently being manufactured
5. **Discontinued**: No longer active

### Managing Perfumes

#### Viewing Perfumes

- **List View**: Table format with sorting and filtering
- **Card View**: Visual cards with key information
- **Search**: Find perfumes by name, category, or tags
- **Filter**: Narrow down by status, category, or date

#### Editing Perfumes

1. **Select Perfume**: Click on the perfume you want to edit
2. **Edit Mode**: Click "Edit" to enter edit mode
3. **Make Changes**: Update information as needed
4. **Version Control**: System automatically tracks changes
5. **Save**: Confirm your changes

#### Deleting Perfumes

⚠️ **Warning**: Deleting a perfume is permanent and cannot be undone.

1. **Select Perfume**: Choose the perfume to delete
2. **Delete Action**: Click "Delete" button
3. **Confirmation**: Confirm the deletion
4. **Cascade Check**: System will warn about related data

## Formula Management

### Creating Formulas

1. **Access Formula Builder**: Go to Formulas → Create New
2. **Basic Information**:
   - **Name**: Descriptive formula name
   - **Description**: Detailed description
   - **Notes**: Additional information

3. **Ingredient Selection**:
   - **Search Ingredients**: Find ingredients by name or type
   - **Add Ingredients**: Click to add to formula
   - **Set Concentrations**: Specify percentage or weight
   - **Adjust Quantities**: Fine-tune amounts

4. **Formula Validation**:
   - **Total Check**: Ensure percentages add up correctly
   - **Cost Calculation**: View estimated costs
   - **Compatibility Check**: Verify ingredient compatibility

5. **Save Formula**: Create the formula record

### Formula Components

#### Ingredient Types

- **Essential Oils**: Natural plant extracts
- **Synthetic**: Laboratory-created compounds
- **Natural Extracts**: Natural but processed materials
- **Fixatives**: Long-lasting base notes
- **Solvents**: Diluting agents
- **Additives**: Special effect ingredients

#### Concentration Levels

- **Top Notes**: 10-20% (evaporate quickly)
- **Middle Notes**: 30-50% (heart of fragrance)
- **Base Notes**: 20-40% (long-lasting)

### Formula Validation

The system automatically validates formulas for:

- **Mathematical Accuracy**: Ensures percentages add up
- **Ingredient Compatibility**: Checks for conflicts
- **Cost Analysis**: Calculates material costs
- **Regulatory Compliance**: Validates against regulations

### Formula Versioning

- **Automatic Versioning**: System tracks all changes
- **Version History**: View previous versions
- **Compare Versions**: See differences between versions
- **Restore Versions**: Revert to previous versions

## Glossary

**Base Notes**: Long-lasting fragrance components that provide depth and longevity

**Concentration**: The percentage of fragrance oil in a perfume

**Essential Oil**: Natural aromatic compounds extracted from plants

**Fixative**: Ingredients that slow down the evaporation of other components

**Formula**: The complete recipe for a perfume including all ingredients and proportions

**Middle Notes**: The heart of a fragrance that emerges after top notes fade

**Perfume**: A complete fragrance product ready for use

**Synthetic**: Laboratory-created fragrance compounds

**Top Notes**: The initial impression of a fragrance that evaporates quickly

**Volatility**: The rate at which fragrance components evaporate
